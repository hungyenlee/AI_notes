#AI #MCP #skill #知識卡

## 一句話

skill 主要回答「AI 該怎麼做」，MCP 主要回答「AI 可以透過什麼受控介面做事」。

## 內容

skill 的強項是保存流程知識，例如 code review 標準、寫作流程、資料整理步驟或品質檢查規則。它像一份可被 agent 按需讀取的 SOP，重點是讓 agent 在特定任務中用正確方法行動。

MCP 則偏向工具能力。它把外部 API、資料庫、SaaS 或內部系統包成 agent 可以發現與呼叫的標準介面。這個介面可以集中處理驗證、權限、稽核與工具 schema。兩者可以搭配：skill 定義流程，MCP 提供流程中可安全呼叫的外部能力。
