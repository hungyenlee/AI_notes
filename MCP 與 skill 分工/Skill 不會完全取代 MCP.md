標籤：#AI #MCP #skill

## 一句話

skill 會取代許多個人開發中的 MCP 用途，但不會完全取代 MCP 在治理、授權與標準化分發上的價值。

## 內容

「skill 是否會取代 MCP」要先看使用場景。若 agent 已經能使用 shell、讀寫檔案並執行 CLI，很多 MCP server 只是把既有命令列工具包成另一層介面，反而增加 token、維護與工具發現成本。這時 skill 加 CLI 通常更輕、更直接。

但 MCP 的核心價值不只在執行工具，而在提供標準化、可控、可審計的工具邊界。當任務涉及多用戶授權、OAuth token 保管、租戶隔離、跨平台 client 共用同一套工具時，skill 本身就不夠。skill 更像工作方法，MCP 更像受治理的工具插座。
