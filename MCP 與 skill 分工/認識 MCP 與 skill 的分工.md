## 初步理解

skill、CLI 與 MCP 不是三選一，而是分別處在不同層次。skill 比較像流程知識，負責教 agent 怎麼做；CLI 是執行層，適合直接呼叫本機已有工具；MCP 則是能力層，適合把外部系統包成可治理、可分發的標準工具介面。個人開發者通常可先用 CLI 加 skill，企業或跨平台場景才更需要 MCP。
