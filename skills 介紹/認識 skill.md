## 初步理解

如果 `AGENTS.md` 比較像「這個專案裡的長期工作規則」，那 skill 比較像「遇到某一類任務時可以拿出來用的作業手冊」。

skill 通常不是單純的說明文件，而是 agent 在需要時會讀取並遵循的任務流程。它的價值不在於把所有知識塞進 context，而是讓 agent 先根據 metadata 判斷是否需要使用，等任務真的符合時，再讀取完整流程、參考資料、腳本或模板。
