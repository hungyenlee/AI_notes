`grill-with-docs` 和 `grill-me` 有什麼差別？它為什麼更適合有 codebase 的工程專案？

## 初步理解

`grill-with-docs` 可以理解成工程版的 `grill-me`。它保留一題一題追問、壓力測試計畫的流程，但多了文件化能力，會把討論中形成的專案術語、概念邊界與重要取捨寫進 `CONTEXT.md` 或 ADR。這讓 AI 和開發者下次面對同一個 codebase 時，不需要重新解釋所有背景。
