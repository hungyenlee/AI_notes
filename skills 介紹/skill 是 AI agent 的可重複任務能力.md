## 一句話

skill 是一種封裝任務方法的知識單元，讓 AI agent 面對特定工作時不必每次都從零推理流程。

## 內容

skill 可以包含操作步驟、判斷準則、範例、參考資料、腳本、模板或工具使用規則。當 agent 判斷任務符合 skill 的描述時，就可以讀取該 skill，並把它當作完成任務的工作流程。

skill 適合用在「會重複出現，而且有固定方法」的任務，例如產生文件、整理試算表、處理 GitHub PR、建立 plugin、跑評測、操作瀏覽器或撰寫某種格式的報告。

因此，skill 的重點不是替人類保存一份說明，而是把可重複的做法變成 agent 能夠辨識、讀取並執行的任務能力。
