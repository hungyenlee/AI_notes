#AI #RAG #context #知識卡

## 一句話

RAG 檢索到的資料會被放進模型當下可見的 context，讓模型用這些資料回答問題。

## 內容

`prompt` 是使用者這次下的指令或問題，`context` 則是模型回答當下能看到的全部資訊。RAG 找回來的文件片段不是永久寫進模型記憶，而是被放進這一輪任務的 context，成為模型產生答案時可以參考的資料。關於 context 本身的角色，可以參考 [[context 是 AI 當下能參考的資料包]]。

這也是 RAG 和 memory 的差別。memory 偏向跨對話保存的長期資訊；RAG 偏向在需要時從外部資料源取回相關內容，臨時加入當下 context。換句話說，RAG 不是讓模型真的「記住」資料，而是讓模型在回答前「看見」資料。
