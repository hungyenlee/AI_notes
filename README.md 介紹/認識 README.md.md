## 初步理解

`README.md` 是專案最常見的說明入口文件。它不一定要寫得很長，但應該讓第一次打開專案的人快速知道：這個專案做什麼、怎麼安裝、怎麼執行、怎麼測試，以及遇到問題時該先看哪裡。對 Codex 這類 AI agent 來說，`AGENTS.md` 會先提供工作規則，而 `README.md` 則是在任務需要專案脈絡時，提供理解專案本身的地圖。
