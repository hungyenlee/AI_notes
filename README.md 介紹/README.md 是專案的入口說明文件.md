#AI #README #文件 #知識卡

## 一句話

`README.md` 是專案的主要說明入口，用來幫助讀者快速建立整體理解。

## 內容

對人類來說，`README.md` 通常是第一次進入專案時最先看的文件。對 Codex 這類 AI agent 來說，情況要分開看：`AGENTS.md` 會先被自動載入成工作規則；`README.md` 則是 agent 在理解專案內容、架構與使用方式時，常會主動閱讀的專案說明入口，這個讀取時機可以參考 [[AI agent 會在需要理解專案時讀 README.md]]。

因此 README 應該回答專案的基本問題：這是什麼、解決什麼問題、主要功能是什麼、目前狀態如何，以及讀者下一步該做什麼。

好的 README 不只是介紹文字，也是一種降低進入門檻的導航。它讓讀者不必一開始就在資料夾、設定檔和原始碼裡亂找，而能先取得一張簡單地圖。
