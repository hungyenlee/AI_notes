## 一句話

好的 `README.md` 不只說明專案是什麼，也會讓讀者知道如何安裝、執行、測試和驗證結果。

## 內容

README 最重要的任務之一，是讓新讀者能順利開始。基本內容通常包含：環境需求、安裝方式、啟動指令、測試指令、常見設定，以及最小可行範例。對 AI agent 來說，這些資訊尤其重要，因為它會依照 README 判斷該用什麼指令探索或驗證專案。

如果專案有 harness，README 也應該說明怎麼跑它、輸入資料放哪裡、結果怎麼看。這樣 README 就不只是靜態介紹，而是能引導人或 agent 進入可驗證的工作流程。
