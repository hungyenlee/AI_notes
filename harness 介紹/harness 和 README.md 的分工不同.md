#AI #harness #README #知識卡

## 一句話

`README.md` 幫助人或 agent 理解專案，`harness` 則幫助人或 agent 重複執行與檢查專案行為。

## 內容

`README.md` 比較像專案入口，回答「這是什麼、怎麼開始、有哪些重要指令」。harness 比較像可執行的測試框架，回答「如何用固定方式跑任務、收集結果、判斷是否通過」。

兩者可以互補。好的 `README.md` 會告訴使用者如何啟動或使用 harness；好的 harness 則能讓 `README.md` 裡寫的驗證方式不只是文字說明，而是真的可以被重複執行。對 AI agent 來說，README 提供理解方向，harness 提供可檢查的行動場景。
