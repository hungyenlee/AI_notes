## 一句話

AI harness 的重點，是用固定任務和評分方式反覆觀察 agent 的行為，而不是只看一次漂亮輸出。

## 內容

AI agent 的輸出常有不確定性，所以只靠單次示範很難判斷能力是否真的穩定。AI harness 可以把一組任務、輸入資料、工具限制、預期結果和評分方式整理起來，讓 agent 每次都在相近條件下被測試。

這種做法特別適合比較 prompt、模型、skill、工具設定或 agent 工作流程。當 harness 固定後，開發者就比較容易回答：「這次改動有沒有讓成功率提高？」「錯誤是不是集中在某一類任務？」「agent 是否穩定遵守規則？」
