## 一句話

`memory` 是 AI 系統跨越多次對話保存的長期資訊，但是否存在與如何使用取決於產品或應用設計。

## 內容

memory 常用來保存比較長期的偏好或事實，例如使用者偏好繁體中文、正在進行某個專案、喜歡簡潔回答，或某些固定術語定義。它和當下 prompt 不同，因為 prompt 只屬於這一次互動；它也和 context 不完全相同，因為 memory 不一定每次都完整出現在當下回答裡。

在 AI app 開發中，模型本身通常不會永久把事情寫進「腦袋」。如果應用想讓 AI 記住資訊，通常要由產品或應用層判斷哪些資訊值得保存，寫入資料庫、帳號資料、向量資料庫或其他儲存系統，再在下次需要時取回並放進 context。

以 Codex 來說，memory 是需要啟用的產品層功能，不是模型天生會自動永久記錄。更細的記錄時機與存放位置，可以參考 [[Codex memory 預設不會自動永久記錄]]。
