#AI #軟體測試 #FlakyTest #知識卡

## 一句話

Flaky Test 常見成因是測試依賴了自己無法控制的時間、順序、狀態、並行或外部服務。

## 內容

測試若依賴目前時間、亂數、網路、真實資料庫、檔案系統、第三方 API 或其他測試留下的狀態，就可能在不同機器、不同時間或不同執行順序下得到不同結果。這些外部條件越多，測試結果越容易漂移。

非同步與並行也常造成 Flaky Test。例如 UI 還沒更新就開始 assertion、背景工作還沒完成就檢查資料、平行測試搶同一個資源，這些都會讓測試通過與失敗取決於時機，而不是取決於被測行為本身。
