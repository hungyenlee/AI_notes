## 一句話

Canary Release 先讓少量真實流量使用新版，確認安全穩定後再逐步擴大。

## 內容

Canary Release 實際運作時，會先把新版部署出去，但只讓少量流量使用，例如 1%、5%，或先開給內部員工、特定租戶、特定區域。這讓團隊可以在真實環境下觀察新版，但把可能受影響的人數控制在小範圍。

觀察重點通常是錯誤率、延遲、資源使用量、crash rate、付款成功率或關鍵 API 是否異常。如果監控指標正常，就逐步擴大到更多使用者；如果指標變差，就停止擴大、切回舊版或回滾部署。它的重點不是比較哪個版本更受歡迎，而是確認新版在真實流量下是否安全穩定。
