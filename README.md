# AI 學習筆記

這個資料夾收錄我在學習 AI agent、軟體測試與相關工具時整理的筆記。

筆記內容主要來自我與 Codex Agent 的對話，並搭配部分網站文章與官方文件進行補充。各主題的參考資料集中整理在[資料來源整合](./資料來源整合.md)中。

## 筆記整理方式

這些內容採用卡片盒筆記法整理：每張卡片聚焦一個概念，再透過連結串起彼此的關係。因此，這裡不是依照固定章節編排的完整教科書，而是一組可以逐步探索的知識網絡。

## 建議閱讀順序

1. 先從 [AI 自動化測試心智圖](./AI自動化測試心智圖.canvas)了解各主題之間的關係。
2. 查看[資料來源整合](./資料來源整合.md)，了解筆記引用或參考的對話、網站文章與官方文件。
3. 再依照感興趣的主題，閱讀各資料夾中的卡片筆記，並沿著筆記內的連結繼續探索。

> `AI自動化測試心智圖.canvas` 是 Obsidian Canvas 檔案，建議使用 Obsidian 開啟；在 GitHub 上可以查看原始檔案，但無法呈現完整的互動式心智圖。

## 閱讀提醒

這些筆記是個人學習過程中的理解與整理，並非完整或權威的技術文件。目前若有內容缺漏屬於正常情況，後續會隨著學習與理解持續更新及調整。若閱讀後仍有不清楚之處，或需要確認最新資訊，建議再查閱相關官方文件與其他可靠資料來源。
